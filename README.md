# Copy2HTML

Ferramenta client-side para transformar copy do Word em HTML limpo, previsível e pronto para colar em módulos Liferay.

## Fluxo-alvo

`Word → Copy2HTML → Liferay`

A aplicação é pública, sem login, não exige VS Code e não envia o conteúdo editado para um backend.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Qualidade

```bash
npm test
npm run lint
npm run build
```

> Nunca adicione credenciais, senhas, dados de VPN ou segredos operacionais aos preset packs.
